# ☕ The Sleepy Bean

A cozy coffee shop website built with **HTML**, **Tailwind CSS v4**, and **Vanilla JavaScript**.

---

## 🌟 About The Project

**The Sleepy Bean** is a modern, fully responsive coffee shop website designed to showcase our menu, tell our story, and connect with coffee lovers. The site features a clean, warm design with full support for both **Light Mode** and **Dark Mode**.

---

## 📄 Pages

| Page | Description |
|------|-------------|
| **Home** (`index.html`) | Landing page with hero section, featured items, and more |
| **Menu** (`menu.html`) | Full menu with categories (Hot Drinks, Cold Drinks, Desserts) and live search |
| **About** (`about.html`) | Our story, values, and statistics |
| **Contact** (`contact.html`) | Contact information, WhatsApp integration, and contact form |

---

## ✨ Features

- 🎨 **Modern UI** with Tailwind CSS
- 🌙 **Dark Mode / Light Mode** toggle (saved in localStorage)
- 🔍 **Live Search** functionality
- 📱 **Fully Responsive** (Mobile, Tablet, Laptop, Desktop)
- ✨ **Smooth Animations** (hover, transition, scale)
- 🎯 **Category Filters** on the menu page
- 💬 **WhatsApp Integration** for instant contact
- 📧 **Email & Phone Links** for direct communication
- 🍰 **Beautiful Cards** for menu items with images and prices

---

## 🛠️ Tech Stack

- **HTML5** — Semantic markup
- **Tailwind CSS v4** — Utility-first styling
- **JavaScript** — Interactive features (Dark Mode, Search, Filters)
- **Google Fonts** — Playfair Display & Poppins
